# crosscutter

Administers the DSM-5-TR Cross Cutting Measures as a web app via an LLM-powered chatbot.

## Status

This project is pre-implementation and in early research. There is no working application yet, no source code, and no build configuration in this repository. Nothing here should be expected to run.

## Scope / Direction

- Administers the DSM-5-TR Cross Cutting Measures through an LLM-powered chatbot.
- Planned to evolve into a speech-to-speech chatbot.
- Personal research use only. It is not a clinical or diagnostic tool.

## Disclaimer

This project is not a validated clinical instrument. It is not intended for diagnosis or treatment and is not a substitute for professional clinical judgement.

## Planned Direction / Roadmap

- Build a chat-based administration of the DSM-5-TR Cross Cutting Measures first.
- Explore speech-to-speech interaction later.

These are intended directions, not commitments. No technology stack, framework, timeline, or version numbers have been decided yet.
